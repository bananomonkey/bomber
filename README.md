## Возможности

- авто-распознавание номера: просто пришли его в чат
- избранное: записная книжка номеров с метками и запуском в один клик
- изолированный target у каждого пользователя
- динамическая обязательная подписка (ОП), управление через `/admin`
- ротация прокси, per-host throttling, авто-дисквал мёртвых
- импорт прокси и сервисов файлом или вставкой текста в чат
